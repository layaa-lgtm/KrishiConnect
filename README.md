# KrishiConnect — SIH Frontend

A responsive React + Vite + Tailwind frontend prototype for a demand-driven FPO management platform. The FPO is the seller of produce. Member farmers supply aggregated produce, buyers place orders, completed sales feed future demand forecasts.

## Included

- Responsive FPO dashboard
- AI demand forecast with mock forecast data
- Inventory 
- Orders
- Member farmer procurement network
- Logistics page focused on route sequence optimisation
- Sales & analytics
- Functional buttons, filters, modals, notifications and toast feedback

## Navigation

Dashboard → Demand Forecast → Inventory → Orders → Logistics → Members → Analytics


## Code formatting
The project includes `.editorconfig` and `.prettierrc.json` so the same style can be maintained in VS Code.
